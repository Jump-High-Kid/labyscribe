# labyscribe E2E 인수 체크리스트 (사람 손 · 스모크 게이트)

이 문서는 labyscribe `.mcpb` 를 실제 호스트(Claude Desktop)에 설치하고, **호스트가 자율로
`extract_transcript` 를 호출해 요약**하는 전 과정을 사람이 직접 재현·확인하는 절차다.

> **왜 사람 손인가** — 호스트의 자율 도구호출·요약은 **모델의 비결정적 동작**이다. 결정적
> 보장은 도구층 테스트(`pytest`)가 담당하고, 이 체크리스트는 **스모크 게이트**(실환경 1회 확인)로
> 그 위를 덮는다. 실패해도 **사용자 주도 폴백**(수동 페이징·붙여넣기)이 항상 존재한다(§5).

각 실행 결과는 반드시 **§4 버전 기록란**에 남긴다(비결정성 때문에 버전 컨텍스트가 중요).

---

## 1. 설치 · 저장 위치 확인

### macOS

- [ ] `labyscribe.mcpb` 를 연다 → Claude Desktop 이 확장으로 설치한다.
- [ ] 미서명 경고가 뜨면 [README 의 Gatekeeper 우회](../README.md#미서명-안내-gatekeeper-우회) 절차로 진행한다.
- [ ] 확장 설정에서 **저장 위치**(기본 `~/labyscribe`)를 확인한다.

### Windows

- [ ] `labyscribe-win.mcpb` 를 연다 → Claude Desktop 이 확장으로 설치한다.
- [ ] SmartScreen 경고가 뜨면 **추가 정보 → 실행** 으로 진행한다.
- [ ] 확장 설정에서 **저장 위치**(기본 `%USERPROFILE%\labyscribe`)를 확인한다.

### 공통

- [ ] Claude Desktop 을 재시작하고 확장(도구 `extract_transcript` / `get_transcript_part`,
      프롬프트 `summarize_video`)이 노출되는지 확인한다.

---

## 2. 자율 도구호출 · 요약 · 로컬 보존 (핵심 경로)

- [ ] Claude Desktop 채팅에 **"이 영상 요약해줘 `<URL>`"** 를 입력한다(URL 만 주고 도구 이름은 말하지 않는다).
- [ ] 호스트가 **스스로 `extract_transcript` 를 호출**하는지 확인한다(사용자가 도구를 직접 지목하지 않았는데 호출).
- [ ] 요약이 화면에 표시되는지 확인한다(핵심 요약 + 10분 구간별 상세).
- [ ] 원본 자막이 로컬에 **불변 보존**됐는지 확인한다:
      `~/labyscribe/<video_id>/<lang>-<hash>/` 아래 `transcript.txt` · `raw/<id>.<lang>.vtt` · `meta.json`.
- [ ] 같은 영상을 **재요청**하면 재추출 없이 **캐시 히트**(빠른 재조회)로 처리되는지 확인한다.

---

## 3. 대표 영상군 (각 1편)

각 항목마다 §2 의 자율 호출·로컬 보존을 재확인하고, 페이징 동작을 관찰한다.

- [ ] **짧은 영상 (`<10분` · 수동 자막)** — 단일 part(`total_parts = 1`)로 한 번에 요약되는지.
      예: `https://www.youtube.com/watch?v=jNQXAC9IVRw` (Me at the zoo · 최초 영상).
- [ ] **긴 영상 (`>1시간` · 자동 롤링 자막)** — `total_parts > 1` 이면 호스트가 `summarize_video`
      지시대로 **2번째~마지막 part 를 자동으로 이어받아** 하나로 요약하는지. 자동 완주하지 못하면
      §5 의 **사용자 주도 페이징 폴백**으로 이어받는다.
- [ ] **다국어 영상 (원어 ≠ 한국어)** — **원어 자막**이 선택되고(자동번역이 아니라), 요약은
      한국어로 번역돼 나오는지(고유명사 원어 병기 허용). `meta.json` 의 `orig_lang` 이 원어인지 확인.

> 대표 영상은 시점에 따라 삭제·자막변동 위험이 있으므로, 실패 시 **다른 동류 영상으로 대체**해
> 재현하고, 사용한 URL 을 §4 기록란에 남긴다.

## 5. 실패 시 사용자 주도 폴백 (항상 존재)

호스트가 자율 호출·긴 영상 완주에 실패해도 **다음 폴백으로 항상 요약을 완성**할 수 있다.

1. **수동 도구 지시** — 호스트가 `extract_transcript` 를 스스로 부르지 않으면,
   "`extract_transcript` 로 `<URL>` 자막을 추출해줘" 라고 도구를 직접 지목한다.
2. **수동 페이징** — 긴 영상에서 호스트가 뒷 part 를 안 이어받으면,
   `extract_transcript` 응답의 **`transcript_handle`** 과 **`total_parts`** 를 확인한 뒤
   **`get_transcript_part(transcript_handle, part)`** 를 `part = 2, 3, …, total_parts`
   순서로(1-based) 이어받게 한다. 상세 절차 = [README 의 사용자 주도 폴백](../README.md#긴-영상-페이징--사용자-주도-폴백).
   - 서버/호스트를 재시작했다면 핸들이 무효이므로 `extract_transcript` 를 다시 호출한다(캐시 히트 → 새 핸들).
3. **붙여넣기(최후)** — 페이징 자체가 막히면 로컬 원본을 직접 열어 붙여넣는다:
   `~/labyscribe/<video_id>/<lang>-<hash>/transcript.txt`.

> 어떤 경우에도 **원본 자막은 로컬에 불변 보존**되므로(외부 전송 0), 폴백으로 요약을 마칠 수 있다.
