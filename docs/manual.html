labyscribe 쓰는 법

유튜브 영상을 글로 뽑아서, 평소 쓰는 AI 챗봇에게 요약시키는 프로그램이에요. 컴퓨터를 잘 몰라도 그대로 따라 하면 돼요.

한눈에 — 이게 뭐예요?

  • 유튜브 영상에는 대사가 자막(글)로 들어 있어요. labyscribe는 그 자막을 내 컴퓨터로 깔끔하게 뽑아 줘요.
  • 뽑은 글을 ChatGPT·Claude 같은 AI 챗봇에 붙여넣으면, 그 AI가 영상 내용을 요약해 줘요.
  • labyscribe는 글 뽑는 일만 해요. 요약은 내가 이미 쓰는 AI가 하니까 추가 비용이 없어요.
  • 전부 내 컴퓨터 안에서만 돌아가요. 인터넷에 공개되지 않아요.

시작하기 전에 — 준비물

Windows 준비 끝

받은 실행파일만 있으면 바로 돼요. 따로 깔 게 없어요.

MAC OS 두 가지 먼저

Python(3.10 이상)과 yt-dlp를 먼저 깔아야 해요. 방법은 STEP 1 아래에 있어요.

그리고 공통으로

인터넷 연결, 요약할 유튜브 영상 주소, 그리고 평소 쓰는 AI 챗봇 한 개(ChatGPT·Claude 등)면 충분해요.

STEP 1 · 프로그램 설치하기

Windows

  1. labyscribe-webui-win.zip 내려받기 를 눌러요. (또는 릴리스 페이지 에서 받기)
  2. 받은 파일의 압축을 풀어요.
  3. 안에 있는 labyscribe-web.exe 를 더블클릭해요.

MAC OS

  1. 저장소 ZIP 내려받기 를 눌러, 받은 파일의 압축을 풀어요. (또는 저장소 홈 → 초록색 Code ▸ Download ZIP)
  2. 압축 푼 폴더 안 labyscribe-web.command 를 더블클릭해요.
  3. 프로그램이 Python·yt-dlp가 있는지 먼저 확인해요. 없으면 설치법을 알려주고 멈춰요(자동으로 깔지는 않아요).
주의 · 처음 열 때 경고가 떠요 (정상이에요)

Windows — “Windows의 PC를 보호했습니다” 창이 뜨면 추가 정보 → 실행을 눌러요.

MAC OS — “확인할 수 없는 개발자” 라고 막히면, 그 파일을 마우스 오른쪽 클릭(또는 Control+클릭) → 열기 → 열기 순서로 눌러요. (한 번만 하면 다음부터는 그냥 열려요.)

둘 다 프로그램이 “서명”이 안 돼서 뜨는 안내예요. 이 저장소에서 받은 파일이면 안전해요.

MAC OS만 · Python과 yt-dlp 설치

Python 3.10 이상 — python.org 에서 받거나, Homebrew가 있으면 아래 한 줄:

brew install python

yt-dlp — 아래 중 하나를 터미널에 입력해요:

brew install yt-dlp # Homebrew가 있으면 python3 -m pip install -U yt-dlp # 또는 이 방법

STEP 4 · AI 챗봇에 붙여넣어 요약받기 (제일 중요!)

4

순서대로 두 번만 붙여넣으면 끝

① 화면의 “요약 프롬프트 복사”를 눌러요 → ChatGPT나 Claude 채팅창에 붙여넣어요. (아직 안 보내도 돼요.)

② 이어서 “전체 복사”를 눌러요 → 같은 채팅에 이어 붙여넣고 전송해요.

그러면 AI가 영상 내용을 핵심 요약 + 10분 구간별 상세 + 주요 용어 형태로 정리해 줘요.

팁 · 요약이 너무 길어서 다 읽기 힘들면

①을 누르기 전에 왼쪽의 “분량”을 바꿔요. 전체는 지금처럼 영상 길이에 맞춰 자세히, 10분 읽기는 10분쯤에 읽을 분량, 5분 읽기는 5분쯤에 읽을 분량으로 정리해 줘요.

짧아지는 건 “10분 구간별 상세” 부분이고, 맨 앞의 핵심 요약과 맨 뒤의 주요 용어는 어느 쪽을 골라도 그대로예요. 분량을 고른 뒤에 프롬프트를 복사해야 반영되니, 이미 붙여넣었다면 분량을 바꿔 다시 복사한 다음 새 채팅에 붙여넣으세요.

팁 · 영상이 길어서 “파트”가 여러 개면

아주 긴 영상은 자막이 파트 1·2·3…으로 나뉘어요. “전체 복사”가 한 번에 안 될 만큼 길면, 각 줄의 “복사” 버튼으로 파트 1 → 2 → 3 순서대로 채팅에 이어 붙여넣으면 돼요. 순서만 지키면 됩니다.

STEP 5 · (선택) 파일로 저장하기

5

안 해도 돼요 — 나중에 다시 보고 싶을 때만

“저장 폴더 선택”으로 폴더를 고르고 “이 폴더에 저장”을 누르면, 뽑은 글이 그 폴더에 파일로 저장돼요. 복사해서 바로 쓰는 걸로 충분하니, 필요할 때만 쓰세요.

끄는 법

다 썼으면 검은 창(터미널·콘솔)을 닫으면 꺼져요. MAC OS는 그 창에서 Ctrl+C를 눌러도 돼요.

문제가 생기면

브라우저가 안 열려요

검은 창에 적힌 http://127.0.0.1:… 주소를 복사해 브라우저에 직접 붙여넣어요.

“추출 실패 · NetworkError…” 라며 안 돼요 (파이어폭스)

Edge나 Chrome으로 열면 대개 바로 해결돼요. 검은 창에 적힌 주소(http://127.0.0.1:…)를 복사해 Edge·Chrome 주소창에 붙여넣어 보세요.

파이어폭스를 꼭 쓰려면 — 백신·보안 프로그램이나 브라우저 확장이 내 컴퓨터 안 연결을 막는 경우예요. 파이어폭스 문제 해결 모드(메뉴 ≡ → 도움말 → 문제 해결 모드로 다시 시작)로 열어 보거나, 설정 → 프록시 를 “프록시 없음” 으로 두면 돼요.

“자막을 찾을 수 없습니다” 같은 메시지가 떠요

그 영상에 자막이 없는 경우예요. 자막이 있는 다른 영상으로 해 보세요. (자동 생성 자막이라도 있으면 돼요.)

MAC OS · “yt-dlp가 없습니다”

STEP 1 아래의 yt-dlp 설치 한 줄을 실행한 뒤 다시 열어요.

안심하고 쓰세요

내 컴퓨터 안에서만 동작해요. 서버는 127.0.0.1(내 컴퓨터 자신)에만 열려서, 같은 인터넷의 다른 기기나 외부에서 볼 수 없어요.

자막 추출은 전부 로컬에서 일어나고, 요약은 내가 쓰는 AI가 해요. labyscribe가 내 내용을 어딘가로 보내지 않아요.

뽑은 원본 자막은 저장 위치(~/labyscribe)에 그대로 남아, 나중에 다시 열어 볼 수 있어요.
